# 实剧沉淀的通用规则与例子 V0.4

以下规则来自长篇古装女频项目的完整生产与补拍过程，已去掉具体人物和剧情。它们是通用决策，不是把某部剧写进 Skill。

## 1. 改编

- 先问“保留到什么程度”，再设计节奏。完整保留不等于拖慢，应通过动作、对白、反应和内心声并行提高密度。
- 从30秒拆成两个15秒组时，事件、对白和顺序必须守恒；第二组不重复介绍人物或重播上一动作。
- 首批试写要同时验证内容密度和实际回片总长。计划每组15秒但实际请求16秒，会在长剧中累积成显著超长。

### 可用的微拍点例子

```text
触发：侍女说出衣上血迹来源。
对抗：男方反指女方借伤势博关注。
反应：女方不争辩，只擦净关键物件。
结果：女方平静回应，关系进一步冷却并触发下一句。
```

这四拍可以在一个12—16秒组中并行完成；不能先让所有人站定，再逐句念完。

## 2. 资产

- “角色穿着衣服”不等于“每套衣服都要独立资产”。次要角色单一默认衣留在人设板；主角长期换装、婚服、官服、伤后休养服等才拆分。
- 一旦选入资产，无论主次，都使用完整独立模板，不用“同上”。
- 资产板提示词完整不等于成图文字正确。`generated` 与 `visual_passed` 分开。
- 用户自行补图可以入库，来源记 `manual_import`，按真实路径和文件摘要登记；没有远程任务号不等于不存在。
- 年龄、长期伤势和身份状态由已确认人物图派生；必须保留眉眼、眼距、鼻唇、耳形和自然不对称等身份联系。

### 服装资产最小内容

```text
纯服装静物板；无人物、无人体轮廓、无人台。
正面、背面、内外层、可拆部件、领襟袖口腰带、面料切片、色板、鞋履正侧底。
跨视图衣长、袖长、版型、纹样、扣带和颜色一致。
```

### 场景资产最小内容

```text
空间DNA（门窗、固定家具、材质、光源）；最大主视；反向/侧向视图；
平面或等距灰盒；入口、通路和主机位；状态变化小样；材质、色板、光影样本；
同一空间门窗数量、家具尺度、光源方位和动线一致。
```

### 道具资产最小内容

```text
主视、正背侧顶底或展开视图；结构、材质、颜色、磨损和交互；
文字只写原著明确或制作批准的内容，不自编完整文书冒充原著。
```

## 3. 视频执行提示词

- 源提示词保留完整四区；目标模型执行载荷可以派生出更紧凑的时间段格式，但必须保留源版本与映射。
- 执行载荷开头只写该项目确认的画幅、分辨率、风格和真实风险；不要堆无关负面词。
- 挂图用“序号 + 资产ID + 名称 + 文件”登记，实际上传顺序必须一致。参考数超限在提交前拦截，并保存保留/省略清单。
- 现场对白才张嘴；内心声为同角色画外音且人物闭口。只朗读明确标为声音的原话，不朗读动作说明，不新增旁白。
- 同一句跨切可以连续，但说话人与口型归属不能变化。对白延续到第16秒时，剪辑不能固定裁15秒截掉句尾；可以保留全段或记录轻微提速。

### Vidu 派生执行载荷骨架

```text
<组号｜时长｜画幅/分辨率｜已确认画风与声音限制>
挂图：图1 <资产ID 名称>；图2 <资产ID 名称>……
起点：<承接状态、人物位置、服装、场景>
0–4秒｜<景别与可见动作>。【声音】角色（现场对白，动嘴）：“原话”
4–8秒｜<反应/揭示/物件细节>。【声音】角色（内心声，闭口）：“原话”
8–12秒｜<对抗升级与换机位>。
12–16秒｜<结果与下一组连接>。【声音】角色（现场对白，动嘴）：“原话”
```

时间段是平台执行适配，不替代 Self 源提示词，也不得机械平均为四格；按真实动作和台词容量分配。

## 4. 执行与恢复

- 多个同名工具并存时，先核对已有成功任务实际使用的入口、脚本和参数；不能仅凭名称猜“只能走浏览器”或“某编码不支持”。
- `supported`、`unsupported`、`unverified` 分开。用户选择的编码或模型先实测回读，不静默降级。
- 提交响应丢失属于未知提交，不是失败；先按提示词摘要、资产和时间定位原任务，禁止创建重复任务。
- 平台拒绝、依赖资产阻塞、文字拒绝、本地审批拒绝和本地写入失败必须分开统计。
- 并发满就等空位；额度未刷新就继续停。不能依据本地跨日推断平台额度已经恢复。
- 远端任务已提交后不为排障取消任务或退出账号。

## 5. 质检与补拍

- 文件可解码只说明技术可用，不能证明台词、口型、声线、脸、服装和画面都通过。
- 每组至少抽查多个时间点；分集剪辑再看接缝。自动听写用于发现增漏，但专名同音错误要人工复听。
- 同集某段失败，不用黑屏或无关镜头冒充完整；保留已成功段，列缺口，补片成功后重剪。
- 画面缺陷和台词缺陷分开补。只缺台词时可在不改变剧情的前提下复用同段原音；必须记录来源，不能说成生成模型本身已完整输出。
- 补拍的新稿保存原稿、授权、差异和新任务映射；旧失败不删除。

## 6. 完成口径

永远按真实等级报告：

```text
prompt_ready → submitted → generated → downloaded → tech_passed →
content_passed → rough_cut → fine_cut → published
```

有128集初剪，不等于完成全剧逐句审片或正式发布；有封面提示词，不等于封面已经出图。
