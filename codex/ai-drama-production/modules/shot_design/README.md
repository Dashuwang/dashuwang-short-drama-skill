# Shot Design 模块

将已确认场次拆成目标时长 12—16 秒的可生成组。每个生成组必须明确叙事目标、情绪目标、人物与状态、所用资产、动作、对白、摄影、光影和前后连续性。

V0.2 为短剧加入 `vertical_short_drama_shot_v0.2.md`。文件名保留历史版本名，但其中的密度和动作—对白方法同时适用于 9:16 与 16:9；画幅只改变构图和调度。生成组是模型容器，不等于一个动作或一个传统长镜头；通常包含 3—5 个因果连续的微拍点，并允许多次有叙事作用的景别或机位变化。

默认时长不是死值；复杂动作、对白容量或模型限制需要调整时应记录原因。单个可见分镜通常不少于 1.2 秒且不超过 5 秒。动作与对白必须在生成组数据中建立锚点，提示词不得重新排序。

组表保留制作所需的衣装与状态信息，绑定每位出镜角色已穿对服装的确认人设／换装／状态图。Self 视频正文不再复述服装设计，不能因此删掉剧本或内部组表的服装连续性字段。镜内换装／脱穿／破损先明确前后状态图及动作节点；缺图或不可执行先补资产／拆组，不以文字临时换装。
