# Vidu Q4 闲时适配器 V0.1

状态：`testing`。用于已批准生成组、已确认资产和源提示词的真实 Vidu Q4 闲时执行。不得从小说原文直接进入本适配器。

## 只允许直连

1. **FRAME 直连接口**：通过 `frame_models` 或已验证的本地 FRAME 直连接口读取能力、获取本次零费资格和直连回读。MCP 不通时先检查这个本地桥接，不用普通付费工作流代替。仅访问已知本地接口，不开启浏览器，不臆造供应方路径、参数或能力。实际分辨率、编码、参考类型以选定直连能力为准。
2. **已安装并验证的 Vidu CLI 直连**：用户已指定 CLI 直连时直接用它；没指定具体直连工具时，FRAME 直连不可用可用这一已验证路线。用 CLI 自检和实时额度，提交显式 `nopeak`，不可用默认计费模式。用户明确指定了某个直连工具时，切换工具前先获确认。

本 Skill 不允许打开、检查、登录或操作 Vidu 或 `/idle` 网页，即使只核实资格、费用或音轨也不行。两条直连都走不通就停。不得使用 `claw_pass`、`normal`、积分 API 或其他付费模式替代。

## 进入条件

- 生成组已批准，目标 12—16 秒；不足先合并因果连续内容，超出先拆组。
- 至少一个有效图片参考；图生视频按实时能力通常只允许一张，参考生视频按实时能力限制数量。
- 图片属于当前项目或已同步到目标工具，文件真实存在，上传顺序与载荷一致。
- 提示词、资产版本、时长、画幅、分辨率、编码和输出数完成预检。
- 每一组都在提示词写同次生成的可听原音：对白／闭口心声／剧情画外声按剧本写；无台词也给合适的环境底声或动作声。
- 实时闲时资格有效、费用精确为 0、剩余额度至少 1；任何数字未知都不提交。

## 提交前：分开核对音频输入、原音输出与零费资格

- `audioSupportedInThisNode: false`、无上传音频参考、无音频驱动对口型、只有图片参考，都不证明输出静音。不得用这些字段或报价里只剩额度来推断原音输出。原音用文字提示词表达，不擅自添加平台没有说明的音频开关。
- 原音输出证据只接受两种：**直连能力明确写明本模式支持原音随视频输出**；或**已完成的同一路线原始回片**，可追溯任务，已验证存在音轨且可听内容确由该次生成。条件要匹配直连工具、模型版本、生成类型和 `nopeak`；模式或声音参数改变、接口证据失效时重查。不把历史能力证明当作本次实时额度。未知或证据互相冲突则停在预检，不用新静音任务试错。
- 先取得本次有效精确零费与正额度，保存直连路径、原音证据来源、报价或实时额度回读和本次载荷摘要；已有执行授权内无需反复请用户确认。恢复未知提交时先查原任务，不拿预检输出来授权重提。
- 生成前执行 `python scripts/check_vidu_direct.py 预检记录.json`（路径相对 Skill 根；无 Python 时使用宿主提供的可用 Python）。**脚本未通过、不可运行或证据不全均不得提交。** 这个 JSON 是本地证据记录，不传给供应方；脚本不会联网、下单、验证远端事实或代替费用授权，严禁为了通过填写猜测值。字段示例和判定见[门禁用法](../../scripts/vidu_direct_gate.md)。

## 派生载荷

保留原 `self_prompt_engine` 记录，另建：

```json
{
  "adapter": "vidu_nopeak_V0.1",
  "source_prompt_id": "",
  "group_id": "",
  "prompt_sha256": "",
  "assets": [{"order": 1, "asset_id": "", "version": "", "file": "", "sha256": ""}],
  "duration": 16,
  "ratio": "16:9",
  "resolution": "1080p",
  "codec": "h265",
  "sample_count": 1,
  "schedule_mode": "nopeak",
  "model_version": "live_capability_result",
  "execution_prompt": ""
}
```

字段示例不是固定平台能力；`model_version`、参考数、编码和画幅必须来自本次实时探测。

## 提示词适配

- 用有序挂图行把资产区映射为真实上传文件；源提示词中未实际装载的资产不能写成已上传。
- 保留原对白和动作锚点。现场对白标明动嘴；内心声标明闭口画外音；只朗读标明的原话。
- 执行提示词保留声画同出要求，指定台词、心声、剧情画外声和环境声随同一视频回片生成，不单独配音或换轨。
- 执行提示词可以使用时间段帮助模型调度，但每段必须承载拍点，单镜通常不超过5秒。
- 只写本组真实风险：重复人物、串衣、口型、BGM、血腥、道具跳位等；不要复制无关负面词。
- 超出当前提示词上限时先去重复说明，不能未经授权删原对白或改剧情。

## 提交状态机

1. 完成直连、原音和实时零费用的本地预检门禁。
2. 持久保存批次、组、载荷摘要、资产摘要与 `requesting`。
3. 只提交一次；拿到任务 ID 后记 `submitted`。
4. 超时或断连记 `uncertain`，按原载荷和时间查找唯一任务；不得重新创建。
5. 按真实任务 ID 轮询；并发满只暂停后续。
6. 成功后取无水印地址；地址暂空则有界等待，不用水印版冒充，也不重生。
7. 临时下载、完整解码、核对规格并记录 SHA256 后，原子落正式文件。

## 质量与补拍

- 技术：真实任务、无水印、完整解码、尺寸、编码、时长、音轨、摘要。在任何剪辑或转换前对原始回片用 FFprobe/同等工具确认音轨，再听检或分析验证并非全静音；后置补出的静音流不算。
- 内容：人物/服装/场景/道具、动作、台词、口型、内心声、环境声、禁用画面、镜头密度。缺任一要求的原音内容不得扩批、拼入分集或交付为通过。
- 一组失败只补该组；保留旧任务与原提示词。平台未给原因时记“原因未明”。
- 原音缺失、错词或口型失败按视频组补拍，整组声画一起重生成；先查清原任务状态并重新确认闲时 0 积分，不能单独补轨或从别次回片借声。
- 改稿必须有用户授权，保存原稿、差异和新版本。换图成功不代表文字也通过，两个层面分别记录。

## 费用边界

闲时执行的默认积分上限为 0。普通开发、测试或“开始制作”不授权收费生成。发现费用非0、闲时关闭、额度耗尽或参数不匹配时停止并报告，不做付费兜底。
