# Model Adapter 模块

将已批准的源提示词转换为目标模型支持的派生执行提示词、参数、有序参考图和任务记录，并保留兼容性说明。

适配层只做格式和能力映射，不得覆盖源提示词，不得改写叙事目标、人物身份、资产版本、对白或已批准生成组。具体模型参数易变化，提交前必须读取实时能力和费用，历史成功参数只能作为测试案例。

所有生成组（含无台词镜头和样片）都要确认模型、平台和当前模式能在同一次视频任务输出可听原音，并保留声画同出的提示词。能力不支持或未核实时，不提交，不自动切换到其他模型；只交付标明限制的提示词，或在用户确认符合要求的路线及费用后继续。不能转接独立配音、外加人声对口型或换轨作为兜底。

## 当前路由

- `vidu_nopeak`：读取 `vidu_nopeak_v0.1.md`。只能使用已验证的 FRAME 直连接口或 Vidu CLI 直连，按用户选定工具执行。禁止用网页作能力确认或执行兜底；先用本地门禁核对原音、实时零费和正额度。
- `seedance`：保留平台适配边界；用户必须再选择即梦、Higgsfield 或其他平台，当前 Skill 只交付源提示词与能力预检，不冒充已完成自动提交。
- `prompt_only`：不执行远程生成，只交付源提示词、资产清单和建议参数。

任何闲时路线发现费用非 0、资格未知、额度不足或参数不匹配时立即停止，不能自动回退到积分、`normal` 或 `claw_pass`。
