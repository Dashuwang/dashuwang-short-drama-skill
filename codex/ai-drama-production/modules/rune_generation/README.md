# Rune Generation 模块

根据已确认的故事事实和资产需求，生成可直接复制到生图模型的制符提示词，并登记人工制图、审核、锁定和升版状态。

符就是资产。符体系包含两大类：

- 资产符：人物、服装、场景、道具、生物、界面等稳定视觉资产。
- 技能符：导演、摄影、动作、光影、表演等稳定制作方法的可视化资产。

本模块 V0.2 已冻结制符提示词的共同格式与四类模板。执行时必须先读 `rune_prompt_spec.md`，再读对应类型模板。不得使用旧 V0.1 的普通设定图短提示词，也不得只输出规则文字。

输出仍需人工在生图模型中制作、筛选和确认；确认后才进入资产注册表并锁定。修改已批准资产必须新建版本，不覆盖历史。
