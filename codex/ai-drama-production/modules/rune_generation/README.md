# Rune Generation 模块

根据已确认的故事事实和资产需求，生成可直接复制到生图模型的制符提示词，并登记人工制图、审核、锁定和升版状态。

符就是资产。符体系包含两大类：

- 资产符：人物、服装、场景、道具、生物、界面等稳定视觉资产。
- 技能符：导演、摄影、动作、光影、表演等稳定制作方法的可视化资产。

新项目必须采用 `asset_prompt_format_v0.5.md`。人设和状态采用 20 区，场景采用 13 区，道具／文书／界面／生物采用 12 区，独立服装采用角色绑定的 12＋4 区。导演、摄影、动作、光影、表演技能符仍读 `skill_rune_template.md`。原 `rune_prompt_spec.md`、V0.2 类型模板及 `production_asset_standard_v0.4.md` 仅用于旧项目回溯，不覆盖新版版式、栏目或换装要求。

每个入选资产都必须获得一份完整、独立、可复制的冻结模板提示词。重要性只决定“要不要做”，不能决定“少写哪些栏目”；次要人物、场景、道具、服装、生物和界面同样禁止写“同上”或继承邻项省略。

人物制符先走 [全剧人物差异表](character_differentiation_v0.1.md)：盘点后交 CSV，横向识别检查通过才逐人写提示词；续作读旧表、按稳定 ID 在同一主表追加。该步骤也适用于只交提示词；不改变现有资产类型与 20 区格式。

输出仍需在生图模型中制作、看图质检和确认；确认后才进入资产注册表并锁定。生成成功、文件存在、视觉通过、用户批准和版本锁定必须分别记录。修改已批准资产必须新建版本，不覆盖历史。
