# Prompt Engine 模块

只从已批准的结构化 Shot、已确认资产和项目配置生成视频提示词。提示词属于表达层，不得反向修改故事事实、人物身份、资产版本、对白或镜头目标；不得从小说原文直接生成最终视频提示词。

## 输入门槛

生成前必须确认：

- Shot 已批准，且包含镜头编号、时长、剧情与情绪目标、动作、表演、对白及连续性。
- 人物、精确状态、场景时间与状态、道具和本镜所需技能符均已登记并确认版本。
- 项目全局风格与本镜覆盖项明确。

任一必需项缺失时，返回缺失项并停止生成最终提示词；容量、对白或连续性问题退回 `shot_design`。

## 路由

| 路由 | 当前实现 | 状态 | 边界 |
| --- | --- | --- | --- |
| `self` | `self_prompt_v0.1/method.md` | `testing` | A 版自己人提示词；固定四区；引导表演与摄影但保留合理发挥空间。 |
| `control` | 未实现 | `reserved` | 保留原有强控制路由，不得借用 self 方法冒充。 |
| `td` | 未实现 | `reserved` | 未来 TD 方法独立版本化；允许秒级、机位、焦段等精密控制，但不得写回 self。 |
| `dual` | 未实现 | `reserved` | 未来并行调用 self 与 TD/control，各自保留独立记录，不合并成不可追溯文本。 |

选择 `self` 时，按顺序读取：

1. `self_prompt_v0.1/method.md`：A 版格式、控制强度和判废条件。
2. `self_prompt_v0.1/integration.md`：输入、输出、版本和上下游边界。
3. 涉及对白时读取 `self_prompt_v0.1/dialogue_demo.md` 校准控制强度；不得复制示例事实到真实项目。

## Self V0.1 执行顺序

1. 核对 Shot、精确状态名、场景时间与状态、道具、对白、连续性和实际可用资产。
2. 建立团队参考框装载清单，只列本镜实际需要的资产。
3. 继承项目全局设定，只追加本场或本镜特殊要求。
4. 生成固定四区 `【镜头编号】`、`【资产】`、`【全局设定】`、`【提示词】`。
5. `【提示词】`第一开头写“承接上一镜头”并自然语言复述人物及精确状态、场景时间与状态；中段引导演员动作、眼神、停顿、表演和镜头调度，同时保留合理发挥空间；结尾写“本镜头最终目标”。
6. 对白逐字保留；不得退化为 B 版，不得用秒级时间线、焦段参数、机位坐标或逐帧动作越界为 TD。
7. 写入 `engine_version=self_prompt_engine_V0.1`、`mode=self` 和输入版本，不覆盖历史记录。

自然语言调用资产，不使用 `@图片` 语法。`【资产】`供团队装载参考，正文对关键资产和状态的自然语言复述是有意的双层绑定，不得删除。

原纯接口版本保存在 `history/v0.1/`，用于追溯，不参与当前路由。
