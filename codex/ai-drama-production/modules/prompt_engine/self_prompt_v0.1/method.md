# 自己人提示词 A 版标准 V0.1

状态：用户确认暂时保留，作为 A/B 测试后的当前正式候选。升级时创建新版本，不直接覆盖本标准。

## 核心定义

自己人提示词把视频模型当作能够理解导演意图的专业合作成员：提供足以说清戏的演员表演、镜头调度和质量引导，但不把每一个动作、机位和时间点全部写死。

固定数据流：

`approved Shot + confirmed assets + project config → self_prompt_engine_V0.1 → A 版自己人提示词`

符提供稳定常量，Shot 提供剧情事实和连续性，提示词负责把二者转换成视频模型可理解的自然语言。

## 固定输出格式

```text
【镜头编号】

【资产】

【全局设定】

【提示词】
```

没有内容的资产类别直接省略。`【全局设定】`保留为固定区；若无本镜追加，简洁写明继承已确认的全剧设定，不复制长篇全局规则。

## 【镜头编号】

写入 Shot 的唯一编号，例如 `S01E02-SC03-SH04`。镜头编号用于团队管理、版本追踪和提示词记录，不承担剧情表达。

## 【资产】

把本区作为团队成员生成视频前的参考框装载清单。按实际需要从下列类别中选择：

- 角色：人物符名称。
- 角色状态：`人物名—符中精确状态标注`。
- 场景：场景符名称。
- 场景时态：白天、黄昏、深夜等符中或项目中确认的时间名称。
- 场景状态：正常、雨夜营业、持续战损等精确状态名称。
- 道具及道具状态。
- 导演符、摄影符、光影符、动作符、表演符等技能资产。
- 角色声音、环境声音、音乐或音效参考。
- 起始帧、结束帧、动作参考或其他视频参考。

只列真正需要放入参考框的资产。不得把资产区写成对符内容的解释。

## 【全局设定】

说明全剧或本场、本镜头应继承的画风、真实度、类型、时代、色彩和整体观感。优先继承项目配置和导演符；只写本镜头需要强调或覆盖的部分。

不得在本区写剧情动作、对白或连续性。

## 【提示词】顺序

### 1. 第一开头：上镜承接与自然语言资产绑定

第一句直接写“承接上一镜头”，并说明本镜头起点。把资产区中的关键对象重新写入自然语言：

```text
承接上一镜头：轻微战损的艾拉落在街道左侧，常态的薇薇安落在街道右侧，二人在黄昏的持续战损状态城市废墟战场中隔着烟尘对峙。
```

人物状态、场景时间和场景状态必须与符的标注逐字一致。资产区负责告诉团队“装载什么”，正文负责告诉模型“这些资产在本镜头是什么状态、如何出场”。

### 2. 剧情与演员表演

写清本镜头的戏剧关系、人物目标、动作、反应、眼神、停顿和必要的心理变化。所有内容必须来自已批准 Shot。

A 版应提供表演路径，使模型知道戏如何成立，但仍允许它根据人物符和导演符合理补全动作衔接与细微表演。不要把所有微动作逐帧写死，也不要完全省略表演要求。

### 3. 对白与声音

逐句写明说话人和原始对白。需要时补充已确认的语气、节奏、停顿、声音状态和环境声音。要求对白归属准确、口型同步、不得抢话或新增旁白。

必须读取 Shot 的动作—对白锚点。标记为动作中的对白，要写成人物一边完成对应动作一边说；标记了 `after_dialogue_action` 时，必须先完整说到指定文字，再发生后续动作。不得为了口型或画面整齐，把动作中的台词移动到人物停下以后。若一句台词按动作节点分段，合并后的文字仍须与原台词逐字一致。

### 4. 导演、摄影与光影

有技能符时使用：

```text
按照东方悬疑文戏导演符、双人对白正反打摄影符和雨夜冷暖对比光影符的要求进行拍摄。
```

再写本镜头特有的调度要求，例如景别丰富度、切镜节奏、主体可读性、动作因果或文戏心理重点。可以规定合理的镜头变化数量，但每次变化必须服务叙事。

没有导演符时，可写“请你作为一位擅长……的电影导演”；没有摄影符或光影符时，才用自然语言补足对应要求。

### 5. 补充与避免事项

只追加与本镜头真实失败风险有关的要求，例如人物状态漂移、道具跳位、口型错误、视线错位、动作穿模、空间关系混乱或特效遮挡主体。不要堆砌与任务无关的通用负面词。

### 6. 结尾：本镜最终目标

最后用“本镜头最终目标”写明剧情必须到达的结果、人物和资产结束状态、最后画面，以及下一镜头连接方向。

结束目标描述结果和可剪辑画面，不得擅自改变 Shot 事实。

## A 版控制强度

应当明确：

- 人物在本镜头中的主要动作和反应。
- 表演应呈现的情绪变化和关键眼神或停顿。
- 镜头需要服务的叙事重点、节奏与丰富度。
- 必须保留的对白、开始状态和结束目标。

应当保留自由：

- 动作之间的自然连接。
- 次要表情和细微身体反应。
- 满足导演符与摄影符后的具体机位选择。
- 不影响连续性和剧情事实的构图、切镜与运镜优化。

不得变成：

- B 版：只给剧情目标，完全不引导演员表演和镜头调度。
- TD 版：逐秒、逐机位、逐焦段、逐动作强制执行。

## 直接判废条件

- 正文没有自然语言点名人物、精确状态、场景时间或场景状态，只在资产区列出。
- 上镜承接没有写进提示词第一开头。
- 本镜结束目标没有写在提示词结尾。
- 状态名称与符标注不一致或被近义改写。
- 复述整张人物符、导演符或摄影符的全部内容。
- 凭空添加 Shot 中不存在的剧情、能力、动作、对白或资产。
- 对白被改写、换人、删减或添加旁白。
- 动作与对白顺序被颠倒，或把动作中对白改成动作完成后站定念词。
- 15 秒竖屏短剧 Shot 只有一个 3—5 秒有效动作，其余依靠慢镜、喘息、凝视或空镜填充。
- 完全不引导演员表演和镜头调度，退化为高自由 B 版。
- 使用秒级时间线和精密参数，越界成为 TD 提示词。
