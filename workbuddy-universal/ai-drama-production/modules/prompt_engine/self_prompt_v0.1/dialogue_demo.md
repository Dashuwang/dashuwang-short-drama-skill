# A 版对白文戏 Demo V0.1

本例用于校准 A 版控制强度。人物、资产和剧情均为虚构示例，不得复制到真实项目数据库。

```text
【镜头编号】
S01E02-SC03-SH04

【资产】
角色：沈砚人设符、林晚人设符
角色状态：沈砚—克制警觉；林晚—表面平静
场景：旧城区茶馆包间场景符
场景时态：深夜
场景状态：雨夜营业状态
道具：密封档案袋道具符
道具状态：密封未开启
导演符：东方悬疑文戏导演符
摄影符：双人对白正反打摄影符
光影符：雨夜冷暖对比光影符

【全局设定】
电影级真人影像质感，克制、冷静的东方悬疑风格。通过人物停顿、眼神、呼吸和细微动作表现心理变化，不使用夸张表情和外放表演。对白场面需要保持潜台词和压迫感，让平静的交谈带有逐渐增强的危险气息。

【提示词】
承接上一镜头：克制警觉的沈砚坐在茶桌左侧，表面平静的林晚坐在茶桌右侧。林晚刚刚将密封未开启的密封档案袋推到茶桌中央，手指仍然压在档案袋边缘。二人在深夜的雨夜营业状态旧城区茶馆包间中隔桌相对，窗外持续传来细密雨声。

沈砚没有立刻触碰档案袋，只是看了一眼林晚压在档案袋上的手，随后缓慢抬起目光观察她的表情。他保持克制警觉，用压低的声音问：

沈砚：“这份名单，你从哪儿拿到的？”

林晚没有马上回答。她安静地看着沈砚，让短暂的沉默形成压力，随后手指轻轻敲了一下档案袋，仍然保持表面平静，不动声色地回答：

林晚：“你真正该问的，是名单里为什么有你的名字。”

台词内容必须保持准确，不改写、不增删，不新增旁白。两人不能同时说话。对白的停顿、呼吸、嘴型和人物反应需要自然同步。沈砚的声音低沉、克制，带有试探；林晚的声音平静、清晰，最后半句话略微放慢，让“你的名字”成为这一镜头的信息重音。

两人对白、窗外细雨和茶馆环境声由本次视频生成随画面一起输出，使用随片原音；不单独配音或后贴。

按照东方悬疑文戏导演符、双人对白正反打摄影符和雨夜冷暖对比光影符的要求进行拍摄。请根据两人的心理攻防合理安排双人关系镜头、过肩正反打、眼神近景、手部细节和反应镜头。15秒内安排不少于3次有叙事作用的景别或机位变化，每次变化都要服务于信息揭示和人物心理，不能为了丰富画面而随意切镜。

镜头节奏前半段保持克制，让沈砚的观察和提问建立试探感；林晚短暂停顿后，镜头节奏逐渐收紧，在她说出“你的名字”时形成这一段对话的情绪落点。合理表现林晚压住档案袋的手指动作、沈砚听到答案后的眼神变化，以及两人之间始终没有完全建立的信任。

保持克制警觉的沈砚、表面平静的林晚、雨夜营业状态的旧城区茶馆包间以及密封未开启的密封档案袋在整个镜头中状态稳定。人物外形、服装、位置和视线关系保持一致。不要出现人物抢话、口型不同步、声音混淆、视线错位、正反打方向混乱、表情过度、无意义走动或道具位置跳变。

本镜头最终目标：林晚说完“你的名字”后保持平静地注视沈砚。沈砚没有回答，呼吸出现极轻微的停顿，目光缓慢落向桌面中央的密封档案袋，克制警觉的表情第一次出现细微裂痕。最后一帧停留在以林晚肩部为前景的过肩近景中，沈砚压制震惊的表情清晰可见，密封未开启的密封档案袋位于画面下方，为下一镜头名单内容的特写提供直接衔接。
```
