# 正式剧本交付格式 V0.5

正式剧本和最终视频提示词分开管理。交付试写集时，也先写适用于全剧的制作总则；尚未确定的总集数、总时长或分批边界明确标「暂定／待确认」，不把首集专属写成全剧规则，也不把只交了试写集说成全剧完稿。逐集版引用同一份总则版本。

## 1. 全剧／全季制作总则——放在合订本最前

- **版本与范围**：剧名、版本、更新、本季或全剧、原作版本、计划覆盖范围、本批实际覆盖与明确续接点；原创注明原创与可索引的故事底稿。区分已确认与待审版本。
- **全剧规格**：题材和受众、画风、成片横竖、计划集数、单集目标时长、分镜组长度与总时长预算；另列本批实际集数/分组数。剧本时长、模型请求、回片和剪后预算分开，标明哪些未试读或未实测。
- **改编与全剧连续性**：改编尺度、叙事顺序、不能改的因果与人物关系、信息揭示边界；对白改动政策、允许的补场和校勘记录。回忆、身份或年龄、衣装、伤妆、场景变化和持物按版本贯通，资产是预登记还是已锁定要写清楚。
- **全剧声音规则**：按开口对白、本人心声、人物可听的剧情画外声、现场环境/动作声分别标注类别和归属；这是剧本标记，不是分轨制作。所有要求的声音随视频模型同次生成，成片只用随片原音，禁止单独配音。明确本项目是否允许 BGM、何种现场音乐例外。本人心声原则上同角色音色、不对口型、别人听不见；不能把门外/电话/门内的剧情台词标成心声。对白随动作，长句如需跨组按自然分句原字续接，不叠读、不靠加速掩盖超载。无 BGM 若为项目决定，全剧统一执行，不只在首集生效。
- **全剧验收**：可见叙事节拍、钩子、相邻组和跨集的衔接、台词试读、关键字可读性和资产一致性。剧本设计用 `△` 写可拍动作；不把源提示词、平台参数、未实测结果写进正式剧本充当已执行记录。

## 2. 分集头——只写本集特有信息

`## 第001集　集名`，随后写本集原著范围／底稿定位、预计时长和分镜组数、上集承接、本集目标、主要反转与结尾钩子。首集注明无上集。范围和规格与全剧一致时可简写，但不能丢来源或时长；有经确认的例外单独列明。不要把整套全剧总则重复在每集开头。

## 3. 每组正式正文——不能写成剧情简介

```text
### G01　00:00—00:15｜原文/底稿锚点（如有）｜场景名／时态／状态

人物：角色名（CH编号）；画外发声者或只出镜无台词者明确标明。
服装与状态：逐人写服装、准确状态和变化；已有 CO/ST 编号则注明，默认与人设绑定时注明，不凭空拆符。
场景：场景名（SC编号）与区域。道具：道具名（PR编号或场景陈设）及起止状态。
群像：类型、数量/是否说话；没有写「无」。
场次状态／组首承接：位置、视线、服装持物、已发生的动作和本组不能提前揭晓的事实。

△ 按因果写可见动作、表演变化和必要的镜头切换；动作不能被心理解释替代。
角色（开口对白，注明动作锚点）：原句。
角色（本人内心声，不对口型）：原句或项目允许的转译；不得冒充原文。
角色（剧情画外对白，注明谁听得到）：原句。

组末衔接：写清结束画面、人物或道具状态，以及下一组从哪个动作/声音接起。
声音：逐组写随片生成的对白、本人心声、环境声、动作声和音乐口径。没有台词就明确无角色发声，仍写场景底声或动作声，不留无声组。
原文定位：章节/段落索引，或原创底稿锚点；制作补写独立标注，不编造原文位置。
```

对白类型按实际写，不要求每组都有三类。15 秒是默认文本分组，不是一个长镜头；通常给 3–5 个因果相连的有效拍点，画面与声音可以并行。逐字留住确认对白、说话人和动作锚点；末组写跨集连接或明确本剧结局。画外发声者未露脸时不要自行补人物长相或可见镜头。

## 4. 随剧本交付的最小附件

- 分集目录／制作范围；逐组声音负载表（集号、组号、起止、来源、开口与心声的总字量、声音类型、同期锚点和试读状态）。字量除组长是组均负载，不是实际说话速度；密集组安排试读。
- 本批资产预登记（去重的统一人物、场景、服装、道具、状态、群像和声音编号；按需求而非凑数；剧本 ID 能查回清单）。
- 交付前核验：时段连贯、组时长加总一致、对白及说话人未偷改、组末状态接得上、编号能对上、已读范围与待续处明示。无真实出图、试读、生成，不写已完成对应环节。
