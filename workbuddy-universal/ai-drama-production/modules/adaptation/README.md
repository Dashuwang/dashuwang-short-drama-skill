# Adaptation 模块

把原作转成可生产的世界、人物、时间线、季、集和场次结构。保留人物动机、关系、因果和核心冲突；支持多季扩展。

开写前必须先冻结改编政策：`full_preservation`（完整保留）、`compression`（适度压缩）、`free_adaptation`（自由改编）或 `original`（原创），并记录允许删改、合并、增补和重排的边界。不得先自行压缩，再把压缩结果当成用户已经批准的方向。

V0.2 新增竖屏短剧节奏方法。项目配置为 9:16、单集约 1—3 分钟或用户明确要求短剧节奏时，必须读取 `short_drama_pacing_v0.2.md`。先建立每集的冲突链和可见事件密度，再分配时长；不得先按传统影视节奏拉长动作、停顿和空镜。横屏项目只改变画面调度，不自动降低短剧事件密度。

批量改编前先试写一至数集，检查开头钩子、每 3—5 秒有效拍点、动作中对白、集尾新问题和总时长预测。样例不通过时只改方法和样例，不扩散错误到全剧。

不得在本模块直接生成最终视频提示词。输出故事理解报告、季规划和集规划后等待人工确认，再生成场次规划。
