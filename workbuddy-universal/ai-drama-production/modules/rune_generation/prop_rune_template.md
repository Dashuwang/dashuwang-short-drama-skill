# 道具、服装、界面符冻结模板

提示词必须使用完整自然语言和 `【】` 分区，横向 16:9 或 21:9。固定顺序如下：

1. `【基础要求】`：说明这是用于 AI 影视生产的稳定资产符，不是广告海报或单一产品图。
2. `【资产信息】`：名称、ID、版本、类型、年代、归属、使用者和剧情功能。
3. `【设计摘要】`：识别核心及其与人物、场景和世界观的关系。
4. `【形态与结构】`：尺寸比例、外形、分件、开合与连接方式。
5. `【材质与颜色】`：必须同时提供视觉材质切片和可见色板。
6. `【使用状态与磨损】`：新旧、污渍、折痕、划痕、受力和损坏逻辑。
7. `【版式布局】`：顶部标题；中部主视图；正、背、侧、顶、底或展开视图；底部细节、材质、色板和尺度参照。
8. `【交互与连续性】`：人物如何拿、穿、踢、打开、放置；相邻镜头哪些状态不得改变。
9. `【一致性要求】`、`【文字要求】`、`【画面质量要求】`、`【避免事项】`、`【最终目标】`。

服装符必须显示正背面、分层穿着、面料样本、配件及鞋履；多套服装应按触发场景分状态并保持同一人物体型。界面符必须展示组件、层级、显示与收起状态、留白安全区和真实画面叠加示意，不能只做一张炫技 UI 海报。
