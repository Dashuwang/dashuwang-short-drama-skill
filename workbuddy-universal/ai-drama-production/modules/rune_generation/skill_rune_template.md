# 技能符冻结模板

技能符是制作方法的可视化资产，不是一段规则文本。必须生成横向 16:9 或 21:9 的信息型技能板，并使用 `【】` 分区。

## 通用固定结构

1. `【基础要求】`：说明技能类型、适用项目和可视化资产板性质。
2. `【技能方法概念】`：该技能解决什么问题、希望稳定什么结果。
3. `【核心视觉区】`：用三到六个连续示意画面展示正确方法。
4. `【空间与运动逻辑区】`：灰盒空间、俯视图、箭头、轨迹、焦点和方向关系。
5. `【参数与变化区】`：镜头、节奏、力学、光比或表演强度的可见对比。
6. `【正确与错误对照区】`：至少一组可视化对照，说明漂移、跳轴、失真或污染。
7. `【版式布局】`、`【一致性要求】`、`【文字要求】`、`【画面质量要求】`、`【避免事项】`、`【最终目标】`。

## 类型扩展

- 导演符增加：`【整体风格视觉区】`、`【表演调度区】`、`【镜头语言区】`、`【构图倾向区】`、`【节奏与剪辑逻辑区】`、`【场面调度与空间逻辑区】`、`【导演限制与倾向区】`。
- 摄影符增加：机位高度、焦段、运动路径、轴线、主体与环境占比、起止构图、9:16 安全框示意。
- 动作符增加：骨骼关键姿态、重心、受力、触点、运动轨迹、前后衔接和物理结果。
- 光影符增加：主辅轮廓光位置、光比、色温、曝光、材质响应与日夜/情绪状态对照。

## 去污染强制规则

通用技能符不得出现真实演员、真实名人、电影截图或项目具体人物脸。优先使用灰白无面孔模型、骨骼线稿、运动路径、箭头、灰盒场景、灯位图、明暗球和色板。成片为 9:16 时，在横版技能板中嵌入竖屏构图框进行演示。
