# 全剧人物脸型与身材差异表 V0.1

## 什么时候交付

已确认剧本 → 必要人物资产盘点 → **交付全剧差异 CSV 并完成文字横向对照** → 逐人写／复用人设提示词 → 如有成图，再做并排复核。差异表覆盖已盘点且需要独立人设的全部角色，不只主角，不把一次性群演强行登记。若剧本分批确认，覆盖当前已知范围并在交付时注明范围，后续回到同一张全剧表续补。首次建立和续作都先过这个门；只有场景或道具任务不触发人物差异表。

稳定人物 ID 与剧本、人物资产登记一致；一个人物只占一行。续作先读项目当前差异表和已确认母版，按 ID 补新行，顺带检查旧角色是否会和新人撞脸；必要时只补旧行的易混对象或检查状态，不修改已确认的外形。不按姓名重排 ID，不为换装、伤态或年龄变化另建人物行；这些是原人物的派生资产。确实要修订已确认的外形时，先说明原因并确认，留存旧表与旧母版版本，更新同一主表的当前版，不并行维护两套底表。

## 字段和填写口径

从[空白模板](../../templates/character_differentiation.template.csv)复制；项目交付名建议为 `人物脸型与身材差异表.csv`。首行表头、半角逗号、UTF-8 **带 BOM** 以便 Excel 识别中文；长文本含英文逗号或引号时按 CSV 规则引号转义。保留 ID 的字母与前导零，年龄可用范围例如 `29–31`，身高用厘米。内容按数据写，不写公式。

| 字段 | 填法 |
|---|---|
| 人物ID、角色名、身份、性别、视觉年龄、身高厘米 | 对齐人物登记；年龄是视觉基准，不拿推估值冒充原著。未知而不宜定时标待确认。 |
| 脸型与下颌、颧骨、眉形、眼形与眼距、鼻形、唇形、肤色与年龄感 | 写相对可见的几何特征：如颌角宽钝还是斜收、颧点偏高还是中低、眼距相对眼宽、鼻翼宽窄、唇峰和上下唇厚薄。肤色、纹理和年龄感只作辅助，不靠滤镜或妆造区别。 |
| 身材体态、发型、默认服装与鞋履 | 站姿、肩颈、骨架宽度、躯干与肢体比例、重心或步幅先写；发型、服装另列，不拿来充当脸部识别点。 |
| 易混人物ID、主要区分点 | 用 ID 指向容易混淆的人（多个用 `；` 分隔），写出双方在哪些同角度可见的形态上不同。无高风险对象填「无高风险对象」，仍写本人的固有识别点。 |
| 原著或底稿依据、制作设定说明 | 将明确事实、原文线索及位置先记入依据；把补定内容按字段点名记入制作设定。某字段混有原著与补全时，分别注明两部分，不能用「全部原著」笼统归因。已有母版若与明确原文有冲突，标出冲突请确认，不静默重画或改原著。 |
| 人设母版版本、对照状态 | 未锁定则标待锁定；有母版写资产版本。检查状态按下面的真实证据填写。 |

## 横向对照与回修

1. 先圈同龄、同身份／同制服、亲属、频繁同框等高风险搭配。按剧本同框关系核对，不只比较主角，也不要求全集所有角色两两穷举。
2. 临时忽略发型、衣服、配饰与妆容，按正面、四十五度和中性全身姿态读表。优先检查骨相、五官比例和体态。若只有「剑眉星目、鼻梁挺拔」，回表改成例如「眉峰前段低平，内眦距离略窄，宽钝下颌」对「眉峰靠外上扬，内眦距离偏宽，窄圆下颌」。亲属可共享一两项有依据的家族特征，但要明确各自至少一个面部辨认点，并尽量再写体态差异。避免为分脸而违反原著年龄、亲缘或其他设定。
3. 通过后将确认内容逐人写入 `【面部与识别特征】`、`【身材与体态】`，并同步到 `【人物身份】`、`【发型】`、`【服装形制】`、`【细节与一致性】`，不加新分区。正文写这个角色自身的正向特征和必要边界，不把另一个人的脸列进同张生图提示词。每人都要完整 20 区，不引用「参见差异表」或「同上」。换装、伤态和年龄变化以本人的已确认母版参考为准，明确保留项（例如眼距、鼻唇比例、颌形、耳形）以及允许变化项；没有母版就标待挂图，不重新造脸。
4. 提示词交付后、没有图：只记「已完成文字对照」。若已生图，将高风险人物各取近似角度、取景尺寸、光线和中性表情的脸部图并排看；需要时另比相近姿势的全身图。还缺同角度图记「成图待对照」，不标通过。若成图不易认，先比成图和表：**表里的固有差异不够**，回表修设计并新版本；**表已明确但画面没体现**，修受影响角色的提示词或基准参考再复验，不随意改已确认身份，也不用换发型掩盖。并排实际看过且能区分才记「成图对照通过」；否则记「成图待修」。通过不等于用户批准或母版锁定。

## 去项目化示例

服装另做一次轻量横向核对：在现有「默认服装与鞋履／制作设定说明」字段里落实角色化的形制和鲜亮配色。主要人物在没有制服等约束时，款式与配色都要拉开；不要用服装区别替代上面的去妆造识别检查。明确原著外貌优先，其余设计漂亮而独特，不能全员同一种网红脸。人设和换装成图使用纯白底，详见 [视觉规则](asset_prompt_format_v0.5.md#人设视觉与换装规则)。

[两名同班检修员的差异 CSV](../../examples/character_differentiation.example.csv)：两人相差一岁、常同框且穿同款工服。CH001 用短宽方脸、宽钝颌、偏窄眼距和宽肩短躯干；CH002 用窄长椭圆脸、高颧收颌、偏宽眼距和窄肩长躯干。两行互指为易混对象。对应的[两份完整人设提示词](../../examples/character_differentiation_prompts.md)逐项转写这些固有特征，没有使用参考项目角色。示例仅完成文字对照。
