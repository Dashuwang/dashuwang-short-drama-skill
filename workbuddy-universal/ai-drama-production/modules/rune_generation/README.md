# Rune Generation 模块

根据已确认的故事事实和资产需求，生成可直接复制到生图模型的制符提示词，并登记人工制图、审核、锁定和升版状态。

符就是资产。符体系包含两大类：

- 资产符：人物、服装、场景、道具、生物、界面等稳定视觉资产。
- 技能符：导演、摄影、动作、光影、表演等稳定制作方法的可视化资产。

本模块 V0.2 已冻结制符提示词的共同格式与四类模板。执行时必须先读 `rune_prompt_spec.md`，再读对应类型模板，最后读取 `production_asset_standard_v0.4.md` 的选取、派生和实际成图验收要求。不得使用旧 V0.1 的普通设定图短提示词，也不得只输出规则文字。

每个入选资产都必须获得一份完整、独立、可复制的冻结模板提示词。重要性只决定“要不要做”，不能决定“少写哪些栏目”；次要人物、场景、道具、服装、生物和界面同样禁止写“同上”或继承邻项省略。

输出仍需在生图模型中制作、看图质检和确认；确认后才进入资产注册表并锁定。生成成功、文件存在、视觉通过、用户批准和版本锁定必须分别记录。修改已批准资产必须新建版本，不覆盖历史。
