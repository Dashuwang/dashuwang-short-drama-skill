# 项目开工卡与路由 V0.4

## 快捷启动与原著定位

把原著位置与 `大叔汪开始做新剧` 写在同一条消息里即可。位置可写在启动语前或后；无需特定字段名，资源管理器复制的带引号路径也接受。

- **文件路径**：验证指定文件存在且可读，直接按该文件读取，不另找同名文件。
- **文件夹路径**：只在指定文件夹范围内查找原著。排除剧本改编稿、提示词、项目说明等明显不是原著的文件；若仍有多个合理候选（包括多个版本或待确认的分卷），列出相对路径请用户选择，不按时间或顺序擅自选。
- **只有文件名**：优先匹配本条消息中的附件和当前项目可访问文件，保留扩展名并在重名时列出相对路径。不全盘搜索；不在当前项目或未随消息附上时，请用户贴完整路径或附文件。
- 定位到唯一可读原著后，直接开始原著理解，并继承用户已经给出的设置；还缺关键项时集中问一次。没找到或不可读时说明原因，请用户补可读路径或附件；不把文件名或小说书名当成已读取的正文。

## 一次问清的七项

只询问用户尚未明确的项目。推荐直接发这张简表，让用户按序回答；不逐项来回拖慢。

```text
1. 原著与范围：如尚未定位，请贴文件或文件夹路径、提供当前项目内的文件名，或附上原著；这次做全书、指定章节，还是先做前几集测试？
2. 改编策略：A原著完整保留 / B适度压缩 / C自由改编 / D原创。
3. 画风：真人写实 / 轻写实3D / 国漫3D / 二维动漫 / 其他参考。
4. 题材与受众：题材；男频 / 女频 / 通用。
5. 画幅：横版16:9 / 竖版9:16。
6. 体量：单集时长、预计集数或总时长目标。
7. 制作路线：Vidu闲时 / Seedance（即梦、Higgsfield或其他）/ 只交提示词。
```

若用户说“你决定”，只能对不影响故事方向的技术项给推荐；改编自由度、画幅、收费平台不能替用户决定。短剧没有明确画幅时可推荐 9:16，但必须标为建议而不是已确认事实。

## 路由规则

- `vidu_nopeak`：生成组上限取实时能力，默认目标 12—16 秒；需要图片参考，先做资产；远程生成前证明 0 积分。
- `seedance`：先选择平台，再读取该平台当前模型能力；不要把 Vidu 参数复制过去。
- `prompt_only`：完成剧本、资产提示词、生成组和视频提示词，但所有生成状态保持 `not_executed`。
- 真人写实的生图降噪尾缀应轻；动漫/国漫可以更强。尾缀属于模型适配，不写回原著事实。
- 横竖画幅影响构图与安全区，不改变符板横向 16:9/21:9 的信息资产格式。

## 时长先算账

项目体量必须同时记录：

- `script_seconds`：剧本计划时长；
- `request_seconds`：实际向模型申请的时长；
- `actual_seconds`：回片实测时长；
- `final_budget_seconds`：最终成片目标。

试做一至两集后，用实际回片预测整批总长。预测超出总预算时，先调整分组或精剪策略，再扩批；不能等全剧生成完才发现总长超标。
