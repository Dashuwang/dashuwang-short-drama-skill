# 项目知识库

版本：V0.5.1-testing

## 唯一使命

建立一个精简、通用、可执行的自动做剧 Skill，稳定完成三件事：

1. 小说改编成短剧脚本。
2. 从脚本生成所有必要符资产的制作提示词，并锁定可用资产。
3. 使用脚本和已确认符资产生成视频提示词，按选定模型执行、回收和验收素材。

任何新增内容都必须直接提高这三项能力；否则默认不加入核心 Skill。

## 固定决定

- 符就是资产，包括人物、服装、场景、道具、生物、界面、角色状态等资产符，以及导演、摄影、光影、动作、表演等技能符。
- 先冻结改编政策与范围，再确认试写脚本；先确认关键符，再扩批生成视频。
- 数据只记录连续性、版本、真实执行和验收所需的最小事实，不建设大而全的数据库。
- 模块可独立修改，但对用户呈现时只表现为三个连续生产阶段。
- 单部剧只是测试样本，不进入通用角色或剧情规则。
- 目标模型的执行提示词是源 Shot/提示词的派生版本，不能覆盖源记录。

## V0.4 新增方向

- 新项目先确认：范围、改编策略、画风、题材与男/女频、画幅、时长、制作路线。
- Vidu Q4 闲时创作成为正式执行路线；必须实时证明 `nopeak`、精确 0 积分、剩余额度和参数一致，禁止付费回退。
- 生成组目标 12—16 秒、3—5 个微拍点；单个可见分镜通常 1.2—5 秒。
- 入选资产使用完整模板；默认衣装不滥拆，状态变体从锁定人物图派生。
- 提交、下载、技术验收、内容验收、初剪、精剪和发布分级记录。

## V0.5 格式升级

- 开工卡标准项全点选，只有「特别要求」输入框；支持宿主表单或随包的本地点选卡。
- 正式剧本开头用全剧／全季制作总则；逐集头保留本集细节，逐组写制片字段、声音和具体衔接。
- 资产类型采用 `modules/rune_generation/asset_prompt_format_v0.5.md` 的区序，独立服装默认角色绑定、人物与服装板包含独立的可视声音声线区。旧版本按原格式回溯；技能符保留独立模板。
- 符板保持横向，人物、换装、状态和复杂场景优先 21:9，物件通常 16:9；最终短剧画幅独立选择。
- 视频源提示词使用自然语言描述符与当前状态，不依赖 `@图片` 语法；适配器可以另建有序资产载荷。
- 对白不得擅自改写；动作中对白不得移到动作完成后。
